# Project thesis

## The problem
A person's useful history is scattered among chat exports, emails, calendars, photos, notes and AI conversations. An agent with only the current conversation loses context. A human trying to reconstruct an event has to search across systems. We want to test whether a user-controlled personal system can make that history useful with reliable evidence.

## Candidate identities — decision open
1. **Context for agents:** supply relevant, current, attributable personal knowledge to existing tools. Day-one question: does an agent give a better answer with it?
2. **Personal digital twin:** represent how its owner thinks or would respond. A memory-enabled chatbot alone is not proof that it represents a person. Test against held-out decisions and replies.
3. **Personal prediction:** forecast defined behaviors from historical events. A model of daily activity is a distinct result from a model of preferences or voice.

The three can share inputs; sharing inputs does not make their value or metrics interchangeable. Working description: *a user-controlled personal intelligence system built from digital history, with context, representation and prediction as hypotheses.* Not a finalized pitch.

## First user and use
Start with Safa and Tuna as research participants, using separate private stores. Candidate use: answer a real question about a past event across at least two sources and show the supporting evidence. Compare against each person's existing workflow and a general model. Agree on the question set and success threshold before running the experiment. Neither participant's data goes in the shared repository.

## What is not decided
Product name, audience, commercial versus open-source direction, licensing, deployment, which sources to prioritize, what the user should trust the system to do, and which capability becomes the headline. No claim of complete life coverage, human-level fidelity, validated accuracy, or generalizable prediction.

## Initial decisions
Defter is the working product name (renamed from Brain on 2026-11-14). Pegasim is the GitHub organization hosting the project repo. Start with documentation and review reusable components from both existing projects. Decide joint project governance and code permissions with contributors before broad distribution. Follow the evidence and revise this thesis when the first experiment is complete.
